# Kenny Portes Project 3

## Overview 
This task management app is a responsive React application that features a dynamic task manager 
(To Do List) with filtering capabilities and a controlled contact form. This project demonstrates react 
practices including component nesting, state lifting, and client-side routing.

## Functionality
1. Add Tasks: Create new tasks instantly using the TaskForm.

2. Toggle Status: Mark tasks as completed or active by clicking on the task text.

3. Delete Tasks: Remove unwanted tasks from the list.

4. Filtering: View tasks based on their status: All, Active, or Completed.

5. Visual Feedback: Completed tasks feature a green background and a checkmark (✅).

6. Client-Side Routing: Seamless navigation between Tasks and Contact pages without page reloads using 
react-router-dom.

7. Styled Navbar: A custom blue-themed navigation bar with active links.

## Technologies
- React
- JavaScript
- Bootstrap
- React Router Dom
